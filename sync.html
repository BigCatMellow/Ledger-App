Private repository storage

Ledger stores the latest project snapshot as JSON on the dedicated ledger-data branch of the private repository you choose. Email credentials remain protected in GitHub Actions Secrets.

Automatic sync behavior
1.Open this page once after opening Ledger.
2.Leave this tab open while you use Ledger. It listens for Ledger storage changes and syncs after a short delay.
3.If the tab is closed, reports and automations use the most recent snapshot that reached GitHub.
GitHub Actions secrets required for email

Repository → Settings → Secrets and variables → Actions → New repository secret.

•REPORT_EMAIL_TO — address that receives the report
•SMTP_USERNAME — email account used to send
•SMTP_PASSWORD — app password / SMTP password
•SMTP_FROM — sender address; usually the same as SMTP_USERNAME

The included workflow defaults to Gmail SMTP (smtp.gmail.com:465). For another provider, set repository variables SMTP_HOST and SMTP_PORT.
